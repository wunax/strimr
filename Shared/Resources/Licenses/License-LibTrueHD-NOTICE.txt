LibTrueHD (truehd-atmos-ffi)
C API and Apple packaging of a Dolby TrueHD / Dolby Atmos decoder.

This product includes software from the truehdd project
(https://github.com/truehdd/truehdd): the `truehd` crate (TrueHD/MLP parser and decoder),
Copyright Rainbaby and the truehdd contributors, licensed under the Apache License, Version 2.0.
It is built from https://github.com/superuser404notfound/truehdd, commit
33bae1657ceb25b5fe0347f42c544c3414e2760e: upstream commit
02d29cd0 with performance changes by harletty (https://github.com/harletty/truehdd,
branch fix/huffman-tree-build-memory), which include the change submitted upstream as
truehdd/truehdd#42, and a parser option and a build feature that discard matrix interpolation values.

This product includes the `oamd` crate 0.1.0 (https://github.com/truehdd/oamd), the object
audio metadata parser used by `truehd`, Copyright Rainbaby, licensed under the Apache License,
Version 2.0.

The static library also contains, compiled in, the Rust standard library and these crates,
each available under the MIT license or the Apache License, Version 2.0 (memchr: the MIT
license or the Unlicense): anyhow, bitstream-io, log, memchr, no_std_io2, thiserror.

The truehd and oamd crates are compiled into the static library; their license, the Apache
License, Version 2.0, is in LICENSE-APACHE.

The code in this directory (src/, include/, harness/, tests/, examples/, build.sh) is licensed
under the MIT license; see LICENSE. It frames access units itself, following the
validation rules of truehd::process::extract::Extractor, and computes object metadata update
times per ETSI TS 103 420 clause 5.3.
